## 3. Windows Firewall Configuration

The current Windows network profile is classified as **Public** (`iiitnagpur.local`). Windows Firewall blocks unsolicited inbound connections on Public networks by default unless an explicit firewall rule allows port 8000.

Creating firewall rules requires administrative elevation. If connection from the Mac times out or is refused, run the following command once in an **Administrator PowerShell** on this Windows PC:

```powershell
# Open an elevated (Run as Administrator) PowerShell window on Windows:
New-NetFirewallRule -DisplayName "GALACTUS Backend Port 8000" `
  -Direction Inbound `
  -LocalPort 8000 `
  -Protocol TCP `
  -Action Allow `
  -Profile Any
```

> **Security Note:** Ollama (port 11434) is strictly bound to `127.0.0.1` and is never exposed through the firewall or to the LAN. Only the authenticated, sandboxed FastAPI application on port 8000 is opened.

## 4. CORS Policy

The FastAPI backend has CORS configured to safely accept requests from local development origins without wildcard credential leaks:

- **Explicit Allowed Origins:**
  - `http://localhost:3000`
  - `http://127.0.0.1:3000`
  - `http://localhost:5173`
  - `http://127.0.0.1:5173`
- **Dynamic LAN Subnet Regex:**  
  Allows origins from RFC 1918 private subnets:
  `^https?://(localhost|127\.0\.0\.1|192\.168\.\d+\.\d+|10\.\d+\.\d+\.\d+|172\.(1[6-9]|2\d|3[01])\.\d+\.\d+)(:\d+)?$`
- **Environment Override:**
  Additional custom origins can be appended by setting `$env:MEMORAG_CORS_ORIGINS = "http://my-mac.local:3000"`.
- `allow_credentials` is set to `False` to prevent unauthorized cross-origin credential harvesting.
